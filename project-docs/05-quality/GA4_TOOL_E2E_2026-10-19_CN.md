## Scope

This record verifies that GA4 is available as a global read-only model tool family, not as a project Skill. The test covered service-account authentication, Property discovery, Property metadata, data-stream status, key-event status, Google Ads link status, a historical report, and a realtime report.

Credentials remain outside the repository. No GA4 write method, Measurement Protocol request, Meta Draft, activation, publication, or live execution was used.

- Account summaries: readable; one Property was returned.
- Property details: standard GA4 Property, timezone `Asia/Shanghai`, currency `CNY`.
- Data streams: zero.
- Key events: zero.
- Google Ads links: zero.
- Historical report: zero rows for `sessions`, `activeUsers`, `eventCount`, and `keyEvents`.
- Realtime report: zero rows for `activeUsers` and `eventCount`.
- The Property was created on 2026-10-19 and contains no tracking configuration or historical data yet.

Zero rows mean the Property is not yet instrumented. They do not support any claim about traffic decline, conversion failure, or advertising performance.

## Accuracy Checks

- The Property ID used for reporting is `<ga4_property_id>`. The earlier value `<ga4_account_id>` was the GA4 account ID.
- The Property metadata returned standard service level, `Asia/Shanghai`, and `CNY`.
- Empty data-stream, key-event, Google Ads-link, historical, and realtime results agree with each other.
- The report response preserved the requested date window, metric names, row count, timezone, currency, and property quota.
- The tool result carried `read_only=true` and `source=google_analytics`.

## Limitations

- The property has no website or app data stream, so real traffic, conversion, landing-page, and source/medium analysis remain unverified.
- No Meta-to-GA4 reconciliation was possible because GA4 has no observations to compare.
- GA4 API availability depends on Google OAuth DNS/network reachability. Authentication uses bounded retries and a timeout.
- The Google Analytics MCP is official but experimental and stdio-only; this project uses direct read-only Admin/Data APIs through its own tool gateway.
